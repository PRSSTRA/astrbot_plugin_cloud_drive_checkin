# 云盘签到助手

AstrBot 插件，在普通 QQ 好友私聊中查询、录入和管理云盘签到任务。任务可以按 Cron 自动执行，也可以由用户手动执行；两者共用同一条串行队列。

## 功能

- 查询帮助、任务列表、任务详情、未来三次计划时间和本人绑定状态。
- 在私聊向导中逐个录入任务字段，凭据认证加密后保存。
- 管理本人绑定的暂停状态、自动通知偏好，并在确认后删除绑定和凭据密文。
- 管理员为固定天翼任务或 `direct_env` 通用 Python/Node 任务准备离线制品，并缓存到插件数据目录。
- 管理员按 run_id 取消签到、停用任务，或在普通私聊中受控重载插件。
- 按任务 Cron 自动签到，或使用 `/签到 立即` 手动签到；请求按顺序串行执行。
- 手动终态始终通知；自动结果按本人通知偏好发送。

## 环境要求

- AstrBot 4.29.4 或更新的 4.x 版本。
- Python 3.12 或更高版本。
- 通过 aiocqhttp 适配器接入的 OneBot v11 实现，例如 NapCat；消息上报格式使用 `array`。
- 启用签到执行前，需要一个可用的独立 Docker Neo 部署，并按[配置说明](docs/configuration.md#neo-连接)验证资源清理条件；插件不会自动部署 Neo。
- 部署主密钥 `CLOUD_DRIVE_CHECKIN_MASTER_KEY`，用于加密保存录入值和执行时解密。
- 当前为 `v0.0.1` 开发版本，尚未发布正式版本。

## 安装

```bash
cd /path/to/AstrBot/data/plugins
git clone --branch dev/0.0.1 https://github.com/PRSSTRA/astrbot_plugin_cloud_drive_checkin.git astrbot_plugin_cloud_drive_checkin
```

在 AstrBot WebUI 的插件页确认插件已加载并打开。运行依赖在 `requirements.txt` 中声明；如果 AstrBot 没有自动安装，请在 AstrBot 实际使用的 Python 环境中安装。加载失败时查看日志，修复后重载插件。

主密钥的生成、注入和备份步骤见[配置说明](docs/configuration.md#凭据主密钥)。没有主密钥时，查询和绑定管理仍可使用，录入与手动签到会被拒绝，自动计划在有符合条件用户时以配置错误结束。

## 快速上手

1. 使用 AstrBot 管理员账号私聊机器人，或把普通用户 QQ 加入 `whitelist_qqs`。
2. 发送 `/签到` 或 `/签到 帮助`，确认唤醒前缀、角色和状态存储状态。
3. 在 WebUI 为选定的受支持任务（天翼或 `direct_env` 通用任务，不含移动模板）设置 `enabled=true`、Cron 和时区，并配置 Neo 连接；保持全局 `enabled` 为 `false`，然后执行 `/签到 管理 准备 <任务ID>`。
4. 让参与用户发送 `/签到 录入 <任务ID>` 完成录入。
5. 准备和录入完成后，打开全局 `enabled` 并重载插件，后续计划时间开始自动入队。需要立即验证时发送 `/签到 立即 <任务ID>`。

通用任务使用同一流程：先配置 `direct_env`、固定的脚本提交与摘要、依赖声明，再准备制品并让用户录入。任务配置版本变化后需要重新准备，否则自动计划会以配置错误结束。前置条件和细节见[签到行为](#签到行为)和[配置说明](docs/configuration.md#管理员准备)。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/签到`、`/签到 帮助` | 显示用法、角色、服务开关和状态存储状态。 |
| `/签到 任务 [任务ID]` | 列出任务，或显示字段要求、Cron、时区、未来计划和配置版本。 |
| `/签到 录入 <任务ID>` | 开始 5 分钟字段录入。 |
| `/签到 我的` | 显示本人全部绑定、管理状态和下次自动计划。 |
| `/签到 状态 [任务ID]` | 显示本人绑定、最近签到状态和下次自动计划。 |
| `/签到 立即 <任务ID>` | 提交一次本人手动签到。 |
| `/签到 暂停 <任务ID>` | 暂停本人该任务绑定。 |
| `/签到 恢复 <任务ID>` | 取消本人该任务的暂停标记。 |
| `/签到 通知 <任务ID> 开\|关` | 保存本人该任务的自动通知偏好。 |
| `/签到 删除 <任务ID>` | 发起 60 秒删除确认。 |
| `/签到 删除 <任务ID> 确认` | 确认删除绑定和凭据密文。 |
| `/签到 删除 <任务ID> 取消` | 放弃删除确认。 |
| `/签到 管理 准备 <任务ID>` | 管理员准备该任务的离线制品。 |
| `/签到 管理 取消 <run_id>` | 管理员记录取消请求。 |
| `/签到 管理 停用 <任务ID>` | 管理员写入停用意图和取消请求，并保存 `enabled=false`。 |
| `/签到 管理 重载` | 管理员停止旧实例并加载同一插件。 |

`/签到 我的` 和 `/签到 状态` 不显示字段值、密文、来源会话或字段 ID 清单。任务 ID、凭据是否已配置、暂停与通知偏好、run_id、排队或运行状态、业务结果和通知状态可查询；其他用户不能查看这些记录。

## 权限

只处理普通 QQ 好友私聊。群聊、临时会话、其他平台以及平台或 QQ 身份字段矛盾的事件会被静默忽略，管理员也不豁免。

| 身份 | 获得方式 | 可用指令 |
| --- | --- | --- |
| AstrBot 管理员 | 宿主框架管理员 | 全部查询、本人录入与签到、绑定管理、制品准备、取消、停用和重载 |
| 附加管理员 | 加入 `plugin_admin_qqs` | 与 AstrBot 管理员相同 |
| 白名单用户 | 加入 `whitelist_qqs` | 查询、本人录入与签到、绑定管理 |
| 其他用户 | 无 | 收到无权提示 |

普通用户白名单为空时，所有非管理员用户都会被拒绝。管理员不需要加入白名单。权限在每条指令到达时重新读取，自动计划在准入和执行前也会复查。

## 任务与配置

在 AstrBot WebUI 的插件配置页维护 `enabled`、`plugin_admin_qqs`、`whitelist_qqs`、`timezone`、`timeout_seconds`、`tasks` 和执行相关配置。完整字段、Cron、脚本来源和适配器规则见[配置说明](docs/configuration.md#任务字段)。

内置模板为 `tianyi_cloud`（天翼云盘）和 `mobile_cloud_experimental`（移动云盘，实验），默认禁用。模板只在未配置 `tasks` 时提供，显式设置 `tasks=[]` 不会补回。移动模板必须保持 `enabled=false` 和 `experimental=true`；移动任务不能执行。

通用任务由管理员在 `tasks` 中添加：`input_adapter` 为 `direct_env`，`runtime` 为 `python` 或 `node`，`result_adapter` 为 `json_protocol` 或 `process_only`，并用 `script_url`、`source_commit`、`sha256` 锁定源码。`dependency_bundle` 必须显式为 `none` 或 zip-v1 JSON，源码和依赖是独立固定提交；Python 依赖为可直接导入的纯 Python 模块或包，Node 依赖放在 `node_modules/` 下。含原生扩展或原生文件头的依赖会被拒绝，详见[管理员准备](#管理员操作)。

执行相关配置包括手动冷却、排队有效期、历史保留和任务/用户间隔；默认值和规则见[执行设置](docs/configuration.md#执行设置)。`neo_connection` 默认关闭；手动和自动签到都需要 Neo 连接、启动恢复和访问检查就绪。

## 管理员操作

`/签到 管理 准备 <任务ID>` 只对 AstrBot 管理员和 `plugin_admin_qqs` 开放，在普通 QQ 私聊中使用。准备不启用任务、不建立执行请求，也不读取凭据。

- 支持固定天翼任务和通用任务；移动任务尚未支持。
- 天翼任务从 PyPI 下载锁定 wheel；通用任务下载固定提交的源码，并按声明下载依赖包。准备只校验并打包，不执行下载内容，不在宿主机安装依赖。
- 制品和依赖包各不超过 1 MiB；入口与依赖解压后合计不超过 8 MiB；缓存最多保留 32 个已发布制品、合计 32 MiB。依赖 zip 最多 4096 个成员（含目录项），实际依赖文件最多 4095 个；制品最多 4096 个文件，含 `task.py` 或 `task.js`。
- 依赖中的符号链接、路径穿越、保留名称、原生扩展，以及 ELF、WASM、Mach-O、fat/universal 或真实 PE 文件头会被拒绝。普通 JSON、PEM 和非原生二进制辅助数据可以随包，展开时文件统一为 0600、目录为 0700。
- 成功回复包含任务 ID、制品 SHA256 和字节大小。失败时检查脚本、依赖、下载网络、任务配置或数据目录；状态写入未确认时重载插件后重试。

`/签到 管理 取消 <run_id>` 只记录取消请求。尚未发送业务请求的签到不会执行；已经开始的业务结果可能未知。`/签到 管理 停用 <任务ID>` 先写入停用意图和取消请求，再保存 `enabled=false`；保存未确认时目标禁止执行。`/签到 管理 重载` 在旧实例停止后加载同一插件，未过期排队请求继续，已开始或结果不明的执行不会重跑。

详细前提、失败处理和存储规则见[管理员准备](docs/configuration.md#管理员准备)、[管理员取消](docs/configuration.md#管理员取消)、[管理员停用](docs/configuration.md#管理员停用)和[管理员重载](docs/configuration.md#管理员重载)。

## 签到行为

自动计划按任务 Cron 和 `timezone` 计算。启动、重载、重新打开全局开关或修改任务配置后，只从之后的计划时间开始；停机期间和已经过去的计划不会补跑。同一任务同一计划只入队一次，插件重载、重复检查或时钟回拨都不会再次执行。同一任务已有排队、运行或等待清理的批次时，本次自动计划整体跳过。

手动签到要求全局和任务 `enabled` 为真、Neo 就绪、制品与当前配置版本一致、本人绑定完整且未暂停、当前不在录入向导中，并可使用主密钥。请求入队后持久化并返回 run_id；排队超过 `queue_expiry_seconds` 仍未开始会取消并通知。手动和自动请求共用单 worker 队列，同一时间只执行一个签到；冷却与间隔规则见[执行设置](docs/configuration.md#执行设置)。

执行在独立 Neo Sandbox 中进行，不回退到宿主或 AstrBot 容器。业务结果与退出码分开记录；`json_protocol` 只读取完整 JSON 对象的已知状态，`process_only` 不读取业务结果，没有可靠证据时记为 `unknown`。

手动终态始终发送。自动结果中，`开` 接收全部结果，`关` 只接收失败、需要重新认证、结果未知或配置错误等非成功结果；成功或已签到结果按偏好静默。通知发送失败最多尝试 3 次，发送结果不明或插件在发送中退出时不会盲目重发，也不会因此重跑签到。

## 凭据与安全

- 所有录入字段值都会认证加密后保存，主密钥与密文分开。插件只从环境变量读取主密钥，不生成、不打印；聊天回复不展示凭据值或密文。
- 请备份并保管原主密钥，不要直接更换。当前不提供自动密钥迁移；丢失原密钥后需要重新录入。
- 录入限时 5 分钟，只接受纯文本；可选字段可发送 `/跳过`，全部完成后发送 `/确认`，发送 `/取消` 放弃。值恰好是保留指令或以 `/值 ` 开头时，发送 `/值 原文`。
- 向导期间的消息不会交给 LLM。超时或插件重载后，未完成录入仍会拦截后续私聊文本；发送 `/取消` 后才恢复普通聊天。
- 录入内容作为 QQ 消息传输，QQ、OneBot 实现或框架的入站记录可能保留这些消息，插件无法清除。不能接受这一风险时，不要录入密码或令牌。删除绑定只移除插件保存的绑定与密文，不清理上述入站记录或管理员备份。
- 业务状态、队列、通知、自动计划记录和准备记录保存在 AstrBot 异步 KV 中，制品缓存在插件数据目录。插件不创建数据库或状态文件，只支持单进程、单实例运行。
- 写入未确认时，录入、绑定变更、删除、准备、入队、取消和停用都不会报告成功，插件停止新的执行并暂停调度；恢复后按恢复规则继续，不重放已开始的执行。不要重复提交或手工修改 KV、缓存。

## 验证范围

离线测试、原生框架 smoke 和真实 Neo 假凭据验收的范围与结果见[测试与验证](CONTRIBUTING.md#测试与验证)、[真实 Neo 假凭据验收](CONTRIBUTING.md#真实-neo-假凭据验收)和[通用依赖包验收](CONTRIBUTING.md#通用依赖包)。

真实 Neo 验收只运行测试脚本、固定测试依赖和假凭据，不发起真实云盘签到；原生框架 smoke 使用受控 loopback OneBot 与 FakeBay，不是真实 QQ，也不是完整 Neo 部署。当前没有真实 QQ + 真实 Neo 的完整链路验收，也没有真实云盘账号签到验收；新部署仍需按配置说明单独验证 Neo 清理条件和实际任务网络访问。
